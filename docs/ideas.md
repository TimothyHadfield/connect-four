# Data and theory ideas — Connect Four

Each idea marked **Build** (done) or **Skip** with the reason. 2026-10-20.

| # | Idea | Verdict | Why |
|---|------|---------|-----|
| 1 | **Win / draw / lose chip above every column**, with "in N" turns when the exact distance is known | Build | The core "odds at the point of decision". Book for ≤ 8 discs, live solver after that (Play tab, Table tab, Hint). |
| 2 | **Opening book** from Tromp's 8-ply database + our own solves of the positions it leaves out | Build | Early positions take minutes to solve live; the book makes the first 8 moves instant and exact (128,323 positions, 226 KB). |
| 3 | **Points lost per move** in Review (exact score difference to the best move) | Build | Shows how much each slip cost, not just "mistake". Tags: Best / Good / Slower / Mistake / Blunder. |
| 4 | **Threat map** (odd/even threats) on any reviewed position | Build | Odd/even threat theory is how strong players read Connect Four (first player wants odd-row threats, second wants even). Study › Review › Threats. |
| 5 | **Opening map**: result of each first move on 7×6 | Build | The single most famous fact about the game (only the centre wins). Study › Lab. |
| 6 | **Board-size table** (Tromp's solved results) with your current size outlined | Build | Explains why 6×5 and 5×4 are draws and 8×7 is a first-player win. Study › Lab. |
| 7 | **Cell power heatmap** (how many lines of four pass through each cell) | Build | Simple reason the centre matters: 13 lines through the middle cells vs 3 in a corner. Study › Lab. |
| 8 | **Measured computer strength** table (round robin + vs random) | Build | Required "How strong?" note, numbers from tools/strength.mjs. |
| 9 | **Puzzles**: positions with exactly one winning column, solved exactly | Build | Trains the "find the only move" skill; 27 puzzles, win in 2–7 turns, generated by tools/make-puzzles.mjs and re-checked by a test. |
| 10 | **Real-table companion**: copy a physical board, get the verdict, detect impossible counts | Build | Required; Table tab. |
| 11 | **Pop Out look-ahead values** (+/− scores, forced wins found within the search) | Build | No exact Pop Out solver fits in a phone; a 5-move look-ahead gives honest relative values, labelled as such. |
| 12 | Exact Pop Out solver | Skip | Pekkala needed a large retrograde database; far beyond a static site's budget. |
| 13 | Exact solver for 9×7 | Skip | The size is unsolved (Tromp); the computer uses deep look-ahead there and the Lab says so. |
| 14 | Pop 10 mode | Skip (parked) | A different game (start full, collect 10); would need its own engine and UI. Good later addition if Tim wants it. |
| 15 | "Perfect play line" animation (play out the rest of the game perfectly) | Skip | Perfect lines from early positions take too long to compute on a phone; Review already shows the best column at every step. |
| 16 | Win-probability % against a human-like player | Skip | Connect Four is solved: the honest number is win/draw/loss, not a %. A % would need a human-error model we can't measure. |
| 17 | Elo ratings for the levels | Skip | The pairwise score table already shows strength directly; Elo adds a number without new information. |
| 18 | Mistake heatmap across all your saved games (which move numbers you slip on) | Skip for now | Needs many saved games to say anything; the per-game Review covers it. Revisit if Tim plays a lot. |
